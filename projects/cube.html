Overview

Why build it

I wanted a project that forced me to work across mechanical, electrical, and control systems at once — actuation, sensing, and closed-loop control all had to work together for the cube to actually solve.

The goal from the start was functionality first: get every face turning reliably before worrying about speed.

Early mechanical concept sketch

Actuation and sensing

Each of the six cube faces is driven independently:

  • Six N20 micro metal gearmotors, one per face
  • Quadrature encoders on each motor for closed-loop position feedback
  • TB6612FNG dual-motor driver boards handling motor drive
Motor + encoder + driver detail

Control

An STM32 Nucleo-F767ZI runs a PID position control loop for each face, using encoder feedback to hit precise 90°/180° turns. Face rotations are sequenced from a solve algorithm's move list, translating each move into a target position for the relevant motor.
